Bカート自動カート入れ
iPhone の設定

トーヨー（ミル挽き珈琲CAFE）の発注で、リンクを開くだけで品と数がカートに入るようにします。注文の確定は今までどおり自分で押します。

  1. Userscripts アプリを入れる App Store の「Userscripts」（無料）。
    アプリを開くと「CURRENT DIRECTORY: Userscripts App Documents」と出ます。そのままで OK（変えなくてよい）。
  2. Safari で Userscripts をオンにする 設定 → アプリ → Safari → 機能拡張 → Userscripts
    「機能拡張を許可」をオン。下の「その他の Web サイト」を「許可」にする。
    iOS が古いときは「設定 → Safari → 機能拡張」にあります。
  3. スクリプトを入れる 下のボタンを Safari で開く（文字だらけの画面になりますが正常です）。
    アドレスバー左の 「ぁあ」または パズルのマーク → Userscripts → 「Userscript Detected」の Install を押す。 スクリプトを開く
    Userscripts の一覧に「セルフカフェ Bカート自動カート入れ」が出ていれば完了です。
  4. Bカートにログインしておく Safari で Bカートを開いてログイン。「ログイン状態を保持する」にチェック。
    関東・関西・東海でアカウントが別なので、使う地域のアカウントで。 Bカートを開く
  5. 試す 下のボタンで、専用グラニュー糖が 1 袋カートに入ります。画面の上に「✓ 専用グラニュー糖 ×1」と出れば成功。 試しにカートに入れる
    試したあとは、カートの画面で砂糖を「削除」してください。
    初めての時に Safari が「Userscripts にこのサイトへのアクセスを許可しますか」と聞いたら「許可」。

うまくいかないとき

・何も出ない → 2 の「許可」と、3 の一覧に入っているかを確認。

・「ログインしていません」→ 4 でログインしてから、もう一度リンクを開く。

・それでもだめなら、画面のスクショを Claude に送ってください。
